Consejos

Tips para usar Claude como HRBP

Consejos rapidos para sacarle el maximo partido en S&PE.

🔎

Se especifico con el contexto

Incluye siempre: tu rol (HRBP), la practice, el nivel del audience (MD, People Lead, equipo), y que decision necesitas facilitar.

📊

Pega datos concretos

Claude trabaja mejor con datos. Pega tablas de headcount, attrition, engagement scores. Cuanto mas contexto, mejor el output.

🔄

Itera sin miedo

El primer resultado rara vez es el final. Pide ajustes: "hazlo mas ejecutivo", "anade el impacto en negocio", "reduce a 200 palabras".

🎯

Pide el formato que necesitas

Claude puede darte tablas, emails, one-pagers, HTML con graficos, scripts de conversacion. Especifica el formato desde el principio.
